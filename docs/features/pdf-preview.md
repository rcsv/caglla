# PDFデザインプレビュー機能 - 旅行雑誌風デザイン

PDFのデザイン開発用にHTMLプレビュー機能を実装しました。毎回PDFエクスポートすると費用がかかるため、HTMLでプレビューを確認できるようになりました。

## 🎯 機能概要

- **コスト削減**: PDFエクスポートの代わりにHTMLプレビューでデザイン確認
- **リアルタイム確認**: デザイン変更を即座に確認可能
- **印刷プレビュー**: ブラウザの印刷機能でPDF出力時の見た目を確認
- **認証保護**: トリップの所有者のみアクセス可能
- **旅行雑誌風デザイン**: スッキリ系の旅行雑誌をモチーフにした美しいレイアウト

## 📖 PDF構成（旅行雑誌風）

### 基本仕様
- **A4サイズ縦型、左開き**
- **長辺閉じを前提としたレイアウト**
- **ヘッダ・フッタ付き**（表紙・裏表紙除く）
- **ページ番号表示**

### ページ構成
1. **表紙**
   - Cagllaのロゴとタイトル
   - 旅行期間と目的地
   - 宿泊先・主要アクティビティの紹介
   - グラデーション背景

2. **目次**
   - 旅行タイトルと期間
   - 主要目的地の地図エリア
   - 自動生成の格言
   - 奥付・システム情報

3. **予約情報**
   - 予約データの表示（将来実装）
   - クリーンなレイアウト

4. **旅程（Day 1〜N）**
   - 各日が新しいページから開始
   - 時間順にソートされた旅程
   - 美しいカード形式のレイアウト

5. **緊急連絡先**
   - 緊急時の連絡先情報（将来実装）

6. **Appendix**
   - **チェックリスト**: チェックリスト機能で生成
   - **メモ**: 印刷時のメモエリア + 格言

7. **裏表紙**
   - Caglla情報と注意事項

## 📍 アクセス方法

### 1. APIエンドポイント（直接アクセス）

```
GET /api/trips/[tripSlug]/preview
Authorization: Bearer [Firebase ID Token]
```

**例:**
```bash
curl -H "Authorization: Bearer YOUR_TOKEN" \
     "https://your-domain.com/api/trips/your-trip-slug/preview"
```

### 2. 開発者ツールページ

```
/dev-tools/pdf-preview/[tripSlug]
```

**例:**
```
https://your-domain.com/dev-tools/pdf-preview/tokyo-trip-2024
```

## 🎨 デザイン特徴

### 旅行雑誌風の要素
- **ミニマルデザイン**: 余白を活用したスッキリとしたレイアウト
- **タイポグラフィ**: Helvetica Neueベースの読みやすいフォント
- **カラーパレット**: ブルー系のアクセントカラー
- **ページ構成**: 雑誌のような構成とページ番号

### 印刷最適化
- **A4サイズ**: 標準的な印刷サイズ
- **左開き**: 日本語の読み方に合わせたレイアウト
- **ページ区切り**: 各セクションが新しいページから開始
- **印刷時の調整**: CSS Media Queriesで印刷時の最適化

## 🔧 技術仕様

### テンプレートシステム
- **モジュラー設計**: 各ページが独立したテンプレート
- **共通スタイル**: 統一されたデザインシステム
- **動的コンテンツ**: トリップデータに基づく自動生成

### ファイル構成
```
lib/utils/magazine-pdf-template.ts    # 旅行雑誌風PDFテンプレート
app/api/trips/[tripSlug]/pdf/route.ts # PDFエクスポートAPI
app/api/trips/[tripSlug]/preview/route.ts # HTMLプレビューAPI
```

## 🔒 セキュリティ

- **認証必須**: Firebase ID Tokenが必要
- **所有権確認**: トリップの所有者のみアクセス可能
- **プラン制限なし**: プレビューは無料で利用可能（PDFエクスポートはBackpacker以上）

## 📁 ファイル構成

```
app/api/trips/[tripSlug]/preview/route.ts    # プレビューAPI
app/dev-tools/pdf-preview/[tripSlug]/page.tsx # 開発者ツールページ
lib/utils/trip-template.ts                   # 共通テンプレート
```

## 🔄 テンプレート共有

PDFエクスポートとHTMLプレビューは共通のテンプレートシステムを使用：

- **共通ロジック**: `lib/utils/trip-template.ts`
- **設定可能**: プレビューコントロールの有無を設定
- **保守性向上**: デザイン変更は一箇所で管理

## 💡 開発時の活用方法

1. **デザイン調整**: CSSを変更してプレビューで確認
2. **レイアウトテスト**: 異なるコンテンツ量での表示確認
3. **印刷テスト**: ブラウザの印刷プレビューでPDF出力確認
4. **レスポンシブ確認**: 異なる画面サイズでの表示確認

## 🚀 今後の拡張可能性

- **テーマ切り替え**: 複数のデザインテーマ対応
- **カスタムスタイル**: ユーザー独自のスタイル適用
- **エクスポート形式**: HTML、PDF以外の形式対応
- **プレビュー比較**: 複数デザインの同時表示
