# 左ペインとGoogle Mapsの連動強化機能

## 🎯 概要

Caglla Travel Managerの左ペイン（日程・Itinerary表示）と右ペイン（Google Maps）の連動を強化し、より直感的な旅行計画管理を実現する。

## 🚀 実装可能な連動機能

### 1. Daysエリアクリック時の地図フィルタリング
**機能**: 左ペインの日程（Day）をクリックすると、その日のVenueのみを地図に表示
- 行動予定順にルートを描画
- 他の日程のVenueは一時的に非表示
- 日程ヘッダーに「フィルタ中」インジケーターを表示

**実装難易度**: ⭐⭐⭐ (中)

### 2. Itineraryクリック時の地図フォーカス
**機能**: 左ペインのItineraryカードをクリックすると、地図上で該当Venueにズーム・フォーカス
- マーカーをハイライト表示（色変更・アニメーション）
- インフォウィンドウを自動で開く
- 該当Venueが画面中央に来るようにズーム

**実装難易度**: ⭐⭐ (易)

### 3. 地図マーカークリック時の左ペイン連動
**機能**: 地図上のマーカーをクリックすると、左ペインの該当Itineraryにスクロール
- 該当する日程セクションを自動展開
- Itineraryカードをハイライト表示
- スムーズスクロールアニメーション

**実装難易度**: ⭐⭐⭐ (中)

### 4. ルート表示の強化
**機能**: ルート表示の柔軟な制御
- 日程別ルート表示の切り替え
- 全日程のルート表示/非表示の切り替え
- ルートの色分け（日程別）
- ルートの太さ・透明度の調整

**実装難易度**: ⭐⭐⭐⭐ (難)


### TripMapコンポーネント拡張
```typescript
interface TripMapProps {
  itineraries: Itinerary[]

  selectedItineraryId?: string | null
  onItineraryClick?: (itineraryId: string) => void
  onMarkerClick?: (itineraryId: string) => void

```

### イベントハンドリング
- 左ペインクリック → 地図更新
- 地図マーカークリック → 左ペインスクロール
- キーボードショートカット（Escでフィルタ解除）
