# サポートブランチEOLポリシー

## 📋 概要

このドキュメントでは、サポートブランチ（`support/*`）のEnd of Life（EOL）ポリシーと
ライフサイクル管理について定義します。

---

## 🔄 サポートブランチのライフサイクル

### 1. アクティブサポート期間

**開始**: サポートブランチ作成時  
**終了**: 次のMINORバージョンリリース時

**対象**:
- セキュリティパッチ
- 重要なバグ修正
- ドキュメント更新

**例**:
- `support/v1.8` は v1.9.0 リリース時にアクティブサポート終了
- `support/v1.9` は v1.10.0 リリース時にアクティブサポート終了

---

### 2. セキュリティサポート期間

**開始**: アクティブサポート終了時  
**終了**: 次のMINORリリース後30日

**対象**:
- Criticalセキュリティパッチのみ
- バグ修正は原則対応しない

**例**:
- v1.9.0リリース → v1.8系はセキュリティサポート期間に移行
- v1.9.0リリース後30日 → v1.8系EOL

---

### 3. EOL（End of Life）

**開始**: セキュリティサポート期間終了時  
**以降**:
- ✅ ブランチは保持（アーカイブとして）
- ❌ セキュリティパッチ提供なし
- ❌ バグ修正対応なし
- ⚠️ 新規利用は非推奨

**ブランチの扱い**:
- ブランチ保護を解除
- `README.md` に「Archived」表示
- 実際のブランチは削除せず保持
- タグは全て保持

---

## 📅 サポート期間の計算例

### v1.8系の場合

```
v1.8.0リリース (2025-10-19)
│
├── v1.8.1リリース (2025-10-21) - 型安全性改善
├── v1.8.2リリース (2025-10-21) - セキュリティパッチ
│
v1.9.0リリース (2025-11-XX予定)
├── v1.8系: アクティブサポート終了
└── v1.8系: セキュリティサポート期間開始
    │
    └── v1.9.0リリース後30日 (2025-12-XX予定)
        ├── v1.8系: EOL
        └── support/v1.8: アーカイブ化
```

## 🔒 セキュリティサポート期間の例外

### Critical脆弱性の場合

**条件**:
- CVSS 9.0以上の脆弱性
- 広範囲に影響する認証・認可の問題
- データ漏洩の可能性がある問題

**対応**:
- EOL後でも緊急パッチを検討
- 対応可否は個別に判断
- できるだけ早く新バージョンへの移行を推奨

## 📢 EOLアナウンス

### アナウンスタイミング

1. **MINORリリース時**（アクティブサポート終了）
   ```
   v1.9.0 リリースのお知らせ
   
   - v1.8系はアクティブサポートを終了しました
   - セキュリティサポートはv1.9.0リリース後30日まで継続
   - 新機能開発はv1.9系で行われます
   - v1.9.0への移行を推奨します
   ```

2. **セキュリティサポート期間開始時**（同時）
   ```
   v1.8系 セキュリティサポート期間のお知らせ
   
   - セキュリティパッチのみ提供
   - EOL予定日: 2025-12-XX
   - v1.9.0への移行計画を立ててください
   ```

3. **EOL 2週間前**
   ```
   v1.8系 EOL予告
   
   - EOL日: 2025-12-XX
   - 以降、セキュリティパッチは提供されません
   - 必ずv1.9.0以降に移行してください
   ```

4. **EOL時**
   ```
   v1.8系 EOL完了
   
   - v1.8系のサポートを終了しました
   - セキュリティパッチは提供されません
   - v1.9.0以降への移行を強く推奨します
   ```

## 🗄️ アーカイブ化手順

### 1. ブランチ保護の解除

```bash
# GitHub Settings → Branches → Branch protection rules
# support/v1.8 の保護ルールを削除または無効化
```

### 2. README.mdの更新

support/v1.8ブランチのREADME.mdに追記:

```markdown
## ⚠️ このブランチはアーカイブされています

**サポート状況**: EOL（End of Life）  
**EOL日**: 2025-12-XX  
**推奨バージョン**: v1.9.0以降

このブランチは履歴保存のため保持されていますが、
セキュリティパッチやバグ修正は提供されません。

最新バージョンへの移行を強く推奨します。
```

### 3. AGENTSmdの更新

```markdown
#### support/v1.8 (Archived)
- 状態: 🗄️ アーカイブ（EOL）
- 最終バージョン: v1.8.2
- EOL日: 2025-12-XX
- 推奨: v1.9.0以降への移行
```

### 4. GitHub Branch設定

- "Default branch" を `main` に設定（既に設定済みのはず）
- Archived labelの追加（オプション）

## 📊 移行ガイダンス

### ユーザー向け

#### v1.8系からv1.9.0への移行

**破壊的変更の確認**:
1. `docs/releases/v1.9.0.md` を確認
2. `CHANGELOG.md` で破壊的変更を検索
3. マイグレーションガイドに従う

**移行手順**:
```bash
# 1. バックアップ
git tag backup-v1.8.x

# 2. 依存関係の更新
npm install caglla@1.9.0

# 3. テスト
npm test

# 4. デプロイ
npm run deploy
```

**移行期間**:
- 推奨: セキュリティサポート期間中（30日以内）
- 必須: EOL前までに完了
