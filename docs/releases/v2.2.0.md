# Caglla v2.2.0 リリースノート

**リリース日**: 2025-11-12  
**バージョン**: 2.2.0  
**コードネーム**: "Emerald Journeys"

---

## ✨ ハイライト

- Next.js 15 / React 19 へのアップグレードで最新のプラットフォームを採用
- 予約入力・表示まわりをエメラルドテーマで統一し、アクティビティごとのアイコンやテンプレート運用を強化
- チェックリスト自動生成エンジンを修正し、旅程タグから正しくアイテムが展開されるよう改善

---

## 🧭 主な変更点

### 予約体験の刷新
- `ReservationInfoModal` と `ReservationTemplateModal` を再設計し、緑系のUIと「テンプレートとして保存」導線を追加
- 予約サイトごとのロゴをローカル画像に差し替え (`/public/imgs/*`)、カード幅を広げて2列表示に対応
- 旅程カードの画像右下にアクティビティ種別アイコン（車・木・ベッドなど）を表示
- 予約コード表示を省スペース化し、同一行で時間が潰れないよう調整

### アクティビティとチェックリスト
- `personal_car` / `parking` など交通系タグを追加し、Iconifyアイコンとチェックリストルールを整備
- `lib/checklist-generator` と `/api/trips/[tripSlug]/checklist/generate` を修正し、スラッグ解決・日別旅程の読込・ユーザー認証を安定化
- 「Regenerate Checklist」で正しい件数が生成されるよう距離計算失敗時のスペースやUIを調整

### 旅程編集の快適性
- `InlineTimeEditor` やデフォルト通貨入力など時間・数値系コンポーネントのフォーカス色をエメラルドに統一
- Honolulu など時差の大きい場所でも、ユーザーが手動で選んだタイムゾーンを維持するよう `ScheduleCard` を修正
- 海越えルートで距離計算が失敗しても旅程カードが密着しないよう `VenueDistance` / `TripItineraryView` を改良
- `/[userSlug]/[tripSlug]` ページで認証状態確定を待ってから旅情報を取得し、失敗時は再試行ボタン付きのエラーUIを表示

### ドキュメント
- アクティビティタグ仕様 (`docs/features/activity-tag-checklist-system.md`) を最新カテゴリに更新
- v2.2.0 リリースノートを追加

---

## 🛠 技術的な改善

- Next.js を 15 系、React を 19 系に更新し、`package.json` および `pnpm-lock.yaml` を最新化
- 予約チェックリスト生成APIで Firestore から `day_id` ベースで旅程を取得し、ロギングを強化
- 予約URLバリデーションを https 判定のみに緩和し、多言語エラーメッセージを整備

## 📦 影響範囲

- フロントエンド: 予約ダイアログ、旅程カード、チェックリストビュー、共通アイコン/入力コンポーネント

- ドキュメント: チェックリスト仕様、リリースノート
