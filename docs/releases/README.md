## 📝 リリースノートの書き方

新しいバージョンをリリースする際は、以下の手順でリリースノートを作成してください：

1. **リリースノートファイルの作成**
   ```bash
   cp v1.6.2.md v1.X.X.md
   ```

2. **内容の更新**
   - バージョン番号とリリース日を更新
   - 変更内容を記載
   - コミットハッシュを更新

3. **CHANGELOG.mdの更新**
   - トップレベルの`CHANGELOG.md`に新しいバージョンのエントリを追加
   - 簡潔な変更履歴を記載
   - このリリースノートへのリンクを追加

4. **このREADMEの更新**
   - 上記の「リリースノート一覧」に新しいバージョンを追加

## 📐 フォーマット

リリースノートは以下のセクションを含めることを推奨します：

- **概要**: バージョンの主なハイライト
- **主な変更点**: 機能追加・改善の詳細
- **技術的な改善**: 内部的な改善やリファクタリング
- **影響範囲**: 変更されたコンポーネントやファイル
- **アップグレードガイド**: 既存ユーザーへの影響と移行方法
- **次のバージョンに向けて**: 今後の予定
- **統計**: コミット数、変更ファイル数など
- **完全な変更履歴**: Gitコミットログ
