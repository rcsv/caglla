## 📋 バージョニング方針の策定

### 🎯 Semantic Versioning 準拠
本リリースから、プロジェクトは Semantic Versioning 2.0.0（SemVer）に正式準拠します。

- **MAJOR**: 互換破壊（API/URL/保存形式の非互換変更）
- **MINOR**: 後方互換のある機能追加・大規模UI刷新
- **PATCH**: バグ修正・内部改善（契約不変）

詳細は `docs/development/versioning.md` を参照してください。

## 📋 Technical Details

### バージョニング基準
本プロジェクトにおける「Public API」の定義:
- Next.js API Routes（`app/api/**/route.ts`）のリクエスト/レスポンス仕様
- URLスキーマ（`/[userSlug]/[tripSlug]` などのルーティング規約）
- Firestoreの外部互換を要するスキーマ
- 公開ドキュメント化された環境変数

### 変更種別の判定
- **MAJOR**: Request/Responseの非互換変更、既存URLの破壊、保存形式の非互換変更
- **MINOR**: 任意パラメータの追加、新機能追加、大規模UI刷新（互換維持）
- **PATCH**: バグ修正、内部最適化、ドキュメント誤記修正
