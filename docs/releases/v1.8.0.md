## 🌍 Google Places API 多言語対応

### 🎯 概要
Google Places APIから取得される場所情報（名前、住所、説明等）を複数言語でサポート。ユーザーの言語設定に応じて適切な言語でデータを表示します。

### 🗣️ サポート言語
- 🇯🇵 日本語 (ja)
- 🇬🇧 英語 (en)
- 🇨🇳 中国語（簡体字） (zh)
- 🇰🇷 韓国語 (ko)
- 🇪🇸 スペイン語 (es)
- 🇫🇷 フランス語 (fr)
- 🇩🇪 ドイツ語 (de)
- 🇮🇹 イタリア語 (it)
- 🇵🇹 ポルトガル語 (pt)

---

## 🏗️ 主要機能

### 📍 言語別Places情報取得
- 場所名、住所表記、説明文、営業時間を各言語で取得
- 表示はユーザー設定 → ブラウザ設定 → デフォルト（ja）の優先で決定

### 💾 言語別キャッシュシステム
- 複合キー `{place_id}_{language}` によるキャッシュ
- Firestore最適化と高速アクセス、APIコスト削減

### ⚙️ ユーザー設定統合
- 言語選択と自動検出の統合

---

## 🔧 技術仕様（互換性）

- APIリクエストに `language` 任意パラメータを追加（未指定時は既定ロジック）
- 既存クライアントは無変更で動作（後方互換維持）
- キャッシュ構造は内部非公開資産であり、互換性の対象外
