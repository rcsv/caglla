# Caglla v3.0.1 リリースノート

**リリース日**: 2025年11月30日  
**バージョン**: 3.0.1  
**コードネーム**: "Unified Notifications"

---

## ✨ ハイライト

v3.0.1は、ユーザーエクスペリエンスの統一性を向上させるためのパッチリリースです。ブラウザネイティブの`alert()`と`confirm()`を、統一感のあるカスタムNotificationコンポーネントとConfirmDialogコンポーネントに置き換えました。

### 主な改善点

- **統一された通知システム**: 成功・警告・エラーメッセージを統一されたデザインで表示
- **カスタム確認ダイアログ**: Publish/Unpublish操作時の確認を、アプリの世界観に統一されたダイアログで表示
- **改善されたUX**: ブラウザネイティブのポップアップから、モダンで一貫性のあるUIコンポーネントへ

---

## 🎨 主な変更点

### 新機能

#### Notificationコンポーネント
- Success / Warning / Error の3種類の通知タイプをサポート
- 自動で閉じる機能（デフォルト3秒、カスタマイズ可能）
- スライドインアニメーション
- 右上に固定表示（複数の通知を同時に表示可能）
- `useNotification`フックで簡単に使用可能

#### ConfirmDialogコンポーネント
- Warning / Info / Danger の3種類の確認ダイアログタイプ
- ESCキーまたはオーバーレイクリックでキャンセル
- スライドイン・スケールアニメーション
- Notificationコンポーネントと統一感のあるデザイン

### 改善

#### Publish/Unpublish機能
- **Publish成功時**: `alert()`から`showSuccess()`に置き換え
- **Unpublish確認**: `confirm()`から`showConfirm()`に置き換え
- **Unpublish成功/失敗**: `alert()`から`showSuccess()`/`showError()`に置き換え
- **Unpublish APIエンドポイント修正**: `/api/trip/[tripSlug]/unpublish`から`/api/trip/[tripSlug]/publish`（DELETEメソッド）に修正

#### PDF Export機能
- **PDF出力成功時**: 成功通知を追加
- **エラー表示**: `alert()`から`showError()`に置き換え
- **プラン要件警告**: `alert()`から`showWarning()`に置き換え

#### その他の機能
- **Replicate機能**: エラー表示を`alert()`から`showError()`に置き換え
- **全体的な一貫性**: アプリ全体で統一された通知システムを採用

### 国際化

以下のi18nキーを追加：
- `trip.publish.unpublishConfirmTitle`: Unpublish確認ダイアログのタイトル
- `trip.publish.unpublishConfirmMessage`: Unpublish確認ダイアログのメッセージ
- `trip.publish.unpublishSuccess`: Unpublish成功メッセージ
- `trip.publish.unpublishFailed`: Unpublish失敗メッセージ
- `tripSlugPage.pdfExportSuccess`: PDF出力成功メッセージ

日本語と英語の両方に対応。

## 📝 開発者向け情報

### Notificationコンポーネントの使用方法

```typescript
import { useNotification } from '@/lib/contexts/notification'

const { showSuccess, showWarning, showError } = useNotification()

// Success通知
showSuccess('Published successfully.')

// Warning通知
showWarning('This action requires confirmation.')

// Error通知
showError('An error occurred.')
```

### ConfirmDialogコンポーネントの使用方法

```typescript
import { useNotification } from '@/lib/contexts/notification'

const { showConfirm } = useNotification()

// 確認ダイアログを表示
showConfirm(
  'warning', // 'warning' | 'info' | 'danger'
  'タイトル',
  'メッセージ',
  () => {
    // 確認時の処理
    showSuccess('成功しました')
  },
  () => {
    // キャンセル時の処理（オプション）
  },
  '確認', // 確認ボタンのラベル（オプション）
  'キャンセル' // キャンセルボタンのラベル（オプション）
)
```
