# Release Notes - v1.6.3

**リリース日**: 2025年10月18日

## 📝 概要

v1.6.3では、プロジェクトのドキュメント管理体制を大幅に改善しました。トップレベルに散在していたリリースノートを整理し、業界標準の`CHANGELOG.md`形式に移行することで、長期的なメンテナンス性を向上させました。

---

## ✨ 主な変更点

### 📚 ドキュメント構造の整理

**業界標準に準拠した変更履歴管理**

- **`CHANGELOG.md`の導入**
  - トップレベルに配置
  - [Keep a Changelog](https://keepachangelog.com/ja/1.0.0/)形式に準拠
  - [Semantic Versioning](https://semver.org/lang/ja/)に準拠
  - 簡潔な変更履歴を時系列で管理

- **`docs/releases/`ディレクトリの新設**
  - 詳細なリリースノートを整理して配置
  - `RELEASE_NOTES_v1.6.2.md` → `docs/releases/v1.6.2.md`に移動
  - リリースノート管理ガイド (`docs/releases/README.md`) を追加

- **ドキュメントリンクの整備**
  - `README.md`に変更履歴セクションを追加
  - リリースノート間の相互リンクを整備
  - 各リリースノートから`CHANGELOG.md`へのリンクを追加

---

## 🔄 技術的な改善

### ドキュメント管理システム

- **トップレベルの整理**: リリースノートファイルが散在しない構造
- **管理ガイドの追加**: 新しいリリースを作成する際の手順を明文化
- **フォーマット統一**: 一貫したリリースノートのフォーマット

### ディレクトリ構造

**変更前**:
```
/
├── RELEASE_NOTES_v1.6.2.md
├── RELEASE_NOTES_v1.6.1.md (将来的に増加)
├── RELEASE_NOTES_v1.6.0.md (将来的に増加)
└── ...
```

**変更後**:
```
/
├── CHANGELOG.md (新規)
└── docs/
    └── releases/
        ├── README.md (新規)
        ├── v1.6.2.md (移動)
        └── v1.6.3.md (本リリース)
```

## 🚀 アップグレードガイド

### 既存ユーザーへの影響

- **機能的な変更なし**: ドキュメント構造の整理のみ
- **リリースノートの場所**: トップレベルから`docs/releases/`へ移動
- **変更履歴の確認**: `CHANGELOG.md`で全バージョンの変更を一覧可能

### 開発者向け

- **新しいリリースを作成する場合**
  1. `docs/releases/vX.X.X.md`を作成（テンプレートはv1.6.3を参照）
  2. `CHANGELOG.md`に新しいバージョンのエントリを追加
  3. `docs/releases/README.md`のリリースノート一覧を更新

- **変更履歴の確認**
  ```bash
  # 簡潔な変更履歴
  cat CHANGELOG.md
  
  # 詳細なリリースノート
  cat docs/releases/v1.6.3.md
  ```
