# Release v1.9.0 - ルート最適化機能の完全実装

**リリース日**: 2025-01-23  
**バージョン**: v1.9.0  
**ブランチ**: `support/v1.9`

---

## 🎯 概要

v1.9.0では、ユーザーから長らく要望のあった「Day内のItinerary順序最適化機能」を完全に実装しました。Google Maps APIを活用したルート最適化により、旅行の効率性が大幅に向上します。

---

## ✨ 新機能

### 🗺️ ルート最適化機能
- **最適ルート計算**: Google Maps APIを使用して複数地点の最適な訪問順序を自動計算
- **リアルタイム最適化**: 9箇所の訪問地を50分、23.9kmの最適ルートに最適化
- **視覚的表示**: 最適化されたルートと訪問順序を分かりやすく表示
- **ワンクリック適用**: 最適化された順序をワンクリックでitineraryに適用

### 🎨 UI/UX改善
- **PremiumButton改善**: ツールチップの表示位置を修正し、見切れ問題を解決
- **直感的な操作**: ルート最適化ボタンと適用ボタンの分離で操作性向上
- **エラーハンドリング**: 詳細なエラーメッセージと適切なフォールバック処理

---

## 🔧 技術的改善

### フロントエンド
- **コンポーネント統合**: `DailyRouteOptimizer`を`DayEditor`に統合
- **Props管理**: `TripItineraryView`に`onReorderItineraries`プロパティを追加
- **状態管理**: 最適化結果の表示と適用の状態管理を実装

### バックエンド
- **API連携**: `/api/route-optimization`エンドポイントとの連携
- **データ処理**: itineraryの順序変更とsort_numberの更新処理
- **エラーハンドリング**: サーバーエラー時のクライアントサイドフォールバック

### 認証・認可
- **プラン制限**: Globetrotterプラン以上でのみ機能利用可能
- **API認証**: すべてのAPI呼び出しに適切な認証ヘッダーを追加

## 🐛 バグ修正

### プラン管理
- **プラン同期問題**: `SubscriptionProvider`と`UserDataProvider`の同期競合を解決
- **状態更新**: プラン変更後の状態が正しく反映されるように修正
- **リダイレクト**: プラン変更後のリダイレクトに適切な遅延を追加

### クライアントサイド互換性
- **process is not defined**: クライアントサイドでの`process.env`アクセスを安全化
- **logger互換性**: ブラウザ環境でのlogger動作を改善
- **認証ヘッダー**: `useEntityEditor`で`makeAuthenticatedRequest`を使用

### API改善
- **リクエストボディ検証**: 空のリクエストボディに対する適切な処理
- **JSONパースエラー**: "Unexpected end of JSON input"エラーの解決
- **エラーログ**: 詳細なエラーログ出力でデバッグ性向上

## 📞 サポート

### 既知の問題
- 一部の古いブラウザでGoogle Maps APIの読み込みが遅い場合があります
- 大量のitinerary（20箇所以上）での最適化に時間がかかる場合があります

### トラブルシューティング
- **最適化が失敗する場合**: プラン設定を確認してください
- **ボタンが押せない場合**: ページを再読み込みしてください
- **エラーが発生する場合**: ブラウザのコンソールログを確認してください
