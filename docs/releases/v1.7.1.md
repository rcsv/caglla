## 🌍 Google Places API 多言語対応

### 🎯 概要
Google Places APIから取得される場所情報（名前、住所、説明等）を複数言語でサポート。ユーザーの言語設定に応じて適切な言語でデータを表示します。

### 🗣️ サポート言語
- 🇯🇵 **日本語** (ja)
- 🇬🇧 **英語** (en)
- 🇨🇳 **中国語（簡体字）** (zh)
- 🇰🇷 **韓国語** (ko)
- 🇪🇸 **スペイン語** (es)
- 🇫🇷 **フランス語** (fr)
- 🇩🇪 **ドイツ語** (de)
- 🇮🇹 **イタリア語** (it)
- 🇵🇹 **ポルトガル語** (pt)

---

## 🏗️ 主要機能

### 📍 言語別Places情報取得
- **場所名**: 各言語での正式名称
  - 例: "東京タワー" / "Tokyo Tower" / "东京塔"
- **住所表記**: 言語に応じた住所フォーマット
  - 例: "日本、東京" / "Tokyo, Japan" / "东京，日本"
- **説明文**: 各言語での場所説明
- **営業時間**: 言語に応じた曜日・時間表記
  - 例: "月曜日: 9:00-17:00" / "Monday: 9AM-5PM"

### 💾 言語別キャッシュシステム
- **複合キー方式**: `{place_id}_{language}` でキャッシュ管理
- **効率的なストレージ**: Firestoreでの最適化されたデータ保存
- **高速アクセス**: キャッシュヒット時は瞬時に表示
- **コスト削減**: Places API呼び出しを大幅削減（約$85/月削減）

### ⚙️ ユーザー設定統合
- **言語設定**: ユーザー設定での言語選択
- **自動検出**: ブラウザ設定からの言語自動検出
- **優先順位**: ユーザー設定 → ブラウザ設定 → デフォルト（日本語）

## 🔧 技術仕様

### 📝 型定義の拡張
```typescript
// Places Cache の更新
interface PlacesCache {
  place_id: string
  language: SupportedLanguage  // 新規追加
  name: string
  formatted_address: string
  // ... その他のフィールド
}

// サポート言語の型定義
type SupportedLanguage = 'ja' | 'en' | 'zh' | 'ko' | 'es' | 'fr' | 'de' | 'it' | 'pt'
```

### 🔑 キャッシュキー生成
```typescript
// キャッシュキーの生成
getCacheKey('ChIJ123', 'ja')  // "ChIJ123_ja"
getCacheKey('ChIJ123', 'en')  // "ChIJ123_en"

// Firestoreドキュメント構造
places_cache/
  ├─ ChIJ123_ja  // 日本語版
  ├─ ChIJ123_en  // 英語版
  └─ ChIJ123_zh  // 中国語版
```

### 🌐 Places API統合
```typescript
// 言語パラメータの動的設定
placesApiHelpers.searchPlaces(query, language)
placesApiHelpers.getPlaceDetails(placeId, language)

// Google Places API呼び出し
{
  textQuery: query,
  languageCode: language,  // 動的に設定
  maxResultCount: 20
}
```

## 💰 コスト影響

### Firestoreストレージコスト
- **増加分**: 約$0.144/月（約20円/月）
  - 従来: 100MB
  - 新方式: 900MB（9言語サポート）

### Places APIコスト削減
- **削減額**: 約$85/月（約12,000円/月）
  - キャッシュヒット率50%と仮定
  - 月間10,000リクエストで5,000件のAPI呼び出し削減

### 純益
- **+$84.86/月**: ストレージコスト増加を大きく上回るAPI削減効果

## 🐛 既知の制限事項

### 言語サポート
- Google Places APIがサポートする言語に依存
- 一部の場所では特定言語のデータが不完全な場合がある
- 未サポート言語はデフォルト言語（日本語）にフォールバック

### キャッシュ
- 初回アクセス時はAPI呼び出しが発生（キャッシュミス）
- 人気のない場所×マイナー言語の組み合わせはキャッシュ効果が低い
