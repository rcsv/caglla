# Caglla v3.0.0 リリースノート

**リリース日**: 2025年1月XX日  
**バージョン**: 3.0.0

## ✨ ハイライト

v3.0.0は、Cagllaを**旅行計画アプリから旅行計画SNSへ**進化させるメジャーバージョンアップです。Next.js 15とReact 19の最新機能を活用し、Parallel Routesによる高度なUI実装、SNS機能の追加、そしてアーキテクチャの全面的な刷新を実現しました。

### 主な新機能

- **SNS機能の追加**: いいね、コメント、フォロー機能により、旅行プランを共有し、コミュニティと交流できるようになりました
- **Parallel Routes実装**: タイムライン、地図、SNS機能を独立したスロットで管理し、パフォーマンスとUXを大幅に向上
- **Next.js 15 / React 19対応**: 最新のプラットフォーム機能を活用した高速なレンダリングと優れた開発体験
- **認証プロバイダーマルチ対応**: Google以外の認証プロバイダーにも対応できる基盤を構築

---

## 🧭 主な変更点

### SNS機能

#### いいね機能
- 公開旅行プランにいいねを付けることができます
- リアルタイムでいいね数を表示
- トグル操作で簡単にいいね/いいね解除が可能
- `TripLikeButton`コンポーネントを追加し、Trip詳細とTripCardに統合

#### コメント機能
- 公開旅行プランにコメントを投稿できます
- ネストコメント（返信）に対応
- コメントの編集・削除機能
- `CommentList`と`CommentInput`コンポーネントを実装

#### フォロー機能
- 他のユーザーをフォローして、そのユーザーの公開プランを追跡できます
- フォロワー/フォロー中一覧の表示
- フォロー中ユーザーのフィード表示

#### フィード機能
- 公開旅行プランのフィード表示（`/api/feed/public`）
- トレンドフィード（`/api/feed/trending`）
- フォロー中ユーザーのフィード（`/api/feed/following`）
- 無限スクロールによる効率的なデータ読み込み

### アーキテクチャ刷新

#### Parallel Routes実装
- `@timeline`スロット: タイムライン表示を独立管理
- `@map`スロット: 地図表示を独立管理（フォーカスモード: all/day/single）
- `@social`スロット: SNS機能（いいね・コメント）を独立管理
- 各スロットが独立してデータフェッチ可能になり、段階的な表示が実現

#### Route Groups導入
- `(planner)`: 旅行計画・編集機能
- `(discover)`: 発見・探索機能（将来的に拡張予定）
- `(profile)`: プロフィール機能（将来的に拡張予定）

#### Server Components最適化
- 初期表示をServer Componentsで高速化
- SEO対応の強化
- CDNキャッシュの活用

### 技術的改善

#### Next.js 15 / React 19対応
- Next.js 15.5.6へのアップグレード
- React 19.0.0へのアップグレード
- `params`が`Promise`型になった変更に対応
- `Suspense`バウンダリの適切な配置

#### 認証システムの改善
- 認証プロバイダーマルチ対応の基盤構築
- `google_id`から`auth_uid`への段階的移行
- `getUserByAuthUid()`関数の実装
- 後方互換性を維持しながらの移行

#### 型安全性の向上
- Branded Typesによる識別子型システム（`UserId`, `UserSlug`, `TripId`, `TripSlug`）
- 型安全な比較関数（`isSameUser()`, `isSameTrip()`など）
- SNS関連型定義の追加（`TripSocialStats`, `TripLike`, `TripComment`, `UserFollow`）

#### 権限管理システム
- `lib/core/permissions.ts`に権限チェック関数を実装
- `canViewTrip()`, `canEditTrip()`, `canCommentOnTrip()`, `canLikeTrip()`など
- 公開/非公開状態に応じた適切な権限チェック

### データモデル拡張

#### Firestoreスキーマ拡張
- `trips`コレクションに`social_stats`フィールドを追加
  - `likes_count`: いいね数
  - `comments_count`: コメント数
  - `shares_count`: シェア数
  - `views_count`: 閲覧数
  - `replicas_count`: テンプレート使用回数
- 新規コレクション追加:
  - `trip_likes`: いいね情報
  - `trip_comments`: コメント情報
  - `user_follows`: フォロー関係
- Composite Indexesの追加によるクエリ最適化

#### バックフィル処理
- 既存のTripドキュメントに`social_stats`を自動追加
- 既存データとの互換性を維持

## 🛠 技術的な改善

### API Routes

#### 新規APIエンドポイント
- `GET /api/trip/[tripSlug]/likes`: いいね情報取得
- `POST /api/trip/[tripSlug]/likes`: いいねの追加/削除
- `GET /api/trip/[tripSlug]/comments`: コメント一覧取得
- `POST /api/trip/[tripSlug]/comments`: コメント投稿
- `PUT /api/trip/[tripSlug]/comments/[commentId]`: コメント編集
- `DELETE /api/trip/[tripSlug]/comments/[commentId]`: コメント削除
- `GET /api/users/[userSlug]/follow`: フォロー状態取得
- `POST /api/users/[userSlug]/follow`: フォローの追加/削除
- `GET /api/feed/public`: 公開フィード取得
- `GET /api/feed/trending`: トレンドフィード取得
- `GET /api/feed/following`: フォロー中フィード取得

#### 既存APIの改善
- すべてのAPI RouteでNext.js 15の`params: Promise`型に対応
- エラーハンドリングの統一（`handleApiError`の使用）
- 型安全性の向上

### コンポーネント

#### 新規コンポーネント
- `TripLikeButton`: いいねボタン
- `CommentList`: コメント一覧表示
- `CommentInput`: コメント入力
- `TripFeedList`: フィード表示
- `TripCardSocial`: SNS機能付きTripカード

#### 既存コンポーネントの改善
- `TripPageLayout`: Parallel Routes対応
- `TripHeroSection`: SNS機能統合
- 各種コンポーネントでServer Components/Client Componentsの適切な分離

### ライブラリ・ユーティリティ

#### 新規実装
- `lib/social/trip-likes.ts`: いいね操作
- `lib/social/trip-comments.ts`: コメント操作
- `lib/social/user-follows.ts`: フォロー操作
- `lib/social/feed.ts`: フィード取得
- `lib/core/permissions.ts`: 権限チェック
- `lib/auth/identity-helpers.ts`: 認証ヘルパー拡張

#### 改善
- `lib/core/middleware.ts`: `composeMiddleware`で`params: Promise`を自動解決
- `lib/api/middleware/params.ts`: `withParams()`ミドルウェアの実装

## 🔄 アップグレード手順

### 1. 依存関係の更新

```bash
pnpm install
```

### 2. 環境変数の確認

既存の環境変数に加えて、以下が正しく設定されているか確認してください:
- `NEXT_PUBLIC_GOOGLE_PLACES_API_KEY`
- `NEXT_PUBLIC_UNSPLASH_ACCESS_KEY`（オプション）
- Firebase設定（既存のまま）

### 3. Firestoreルールとインデックスのデプロイ

```bash
firebase deploy --only firestore:rules,firestore:indexes
```

### 4. データマイグレーション（自動実行）

既存のTripドキュメントに`social_stats`フィールドが自動的に追加されます。手動での操作は不要です。

### 5. ビルドとデプロイ

```bash
pnpm build
pnpm start
```

## ⚠️ 破壊的変更

### Next.js 15対応による変更

- **Route Handlerの`params`型**: `{ params: { id: string } }`から`{ params: Promise<{ id: string }> }`に変更
  - すべてのRoute Handlerで`await params`が必要になりました
  - `composeMiddleware`を使用している場合は自動的に解決されます

### APIレスポンス形式

- 一部のAPIレスポンスに`social_stats`フィールドが追加されました
- 既存のクライアントコードは後方互換性が保たれています
