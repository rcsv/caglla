## 📚 追加ドキュメント

### v1.12.0 新機能仕様書（計画）

将来のv1.12.0リリースに向けた4つの主要機能の仕様書を追加しました：

1. **Gmail連携自動予約抽出機能**
   - `docs/specifications/gmail-integration-specification.md`
   - Gmail APIで予約確認メールを自動検出・情報抽出
   - AI（OpenAI GPT-4）を活用した予約情報の自動抽出

2. **Google Calendar連携機能**
   - `docs/specifications/google-calendar-integration-specification.md`
   - 旅程とGoogleカレンダーの双方向同期
   - リアルタイム相互反映、競合解決

3. **AI旅程最適化アシスタント機能**
   - `docs/specifications/ai-itinerary-optimizer-specification.md`
   - OpenAI GPT-4による旅程自動生成・最適化
   - パーソナライズ提案、予算最適化

4. **クォータ管理付きファイルアップロード機能**
   - `docs/specifications/file-upload-quota-specification.md`
   - プラン別ストレージ管理・画像圧縮・重複排除
   - Firebase Storageを活用した高機能アップロードシステム

### 機能概要サマリー

- `docs/specifications/v1.12.0-features-summary.md`
  - 4つの機能の概要、コスト試算、実装スケジュールをまとめたサマリー
  - 総実装期間: 約24週間（6ヶ月）
  - 月間運用コスト: 約24,200円（ユーザー100人想定）
