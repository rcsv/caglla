# Caglla v1.7.0 リリースノート

**リリース日**: 2024年12月19日  
**バージョン**: 1.7.0  
**コードネーム**: "Reservation Manager"

---

## 🎉 メジャーアップデート: 予約情報管理機能

v1.7.0では、旅行計画に欠かせない**予約情報管理機能**を完全実装しました。Itineraryに予約情報を紐付けることで、旅行の準備から実行までを一元管理できるようになります。

---

## ✨ 新機能

### 📋 予約情報管理システム

#### **対応予約タイプ**
- **✈️ 飛行機**: 便名、出発・到着空港、出発・到着日時、航空会社
- **🏨 ホテル**: チェックイン・アウト日時、確認番号、予約サイト
- **🚗 レンタカー**: レンタル期間、確認番号、予約サイト
- **🍽️ 食事**: 予約日時、確認番号、レストラン予約サイト
- **📋 その他**: カスタム予約情報

#### **予約情報フィールド**
- **基本情報**: 予約タイプ、確認番号、予約サイト
- **日時情報**: 開始・終了日時（ローカル時刻対応）
- **URL管理**: 予約サイトへの直接リンク（HTTPS必須）
- **メモ機能**: 自由記述のメモ・備考欄

### 🎨 ReservationInfoModal

#### **スマートな入力体験**
- **情報継承**: Itinerary Cardから予約タイプ・日時を自動設定
- **日時バリデーション**: 終了日時は開始日時以降のみ選択可能
- **リアルタイム検証**: 入力内容の即座なバリデーション
- **ローカル時刻表示**: UTC問題を解決し、現地時刻で表示

#### **予約タイプ別UI**
- **飛行機**: 便名、空港コード、出発・到着日時
- **その他**: 開始・終了日時、確認番号、予約サイト

### 📊 TripReservationDisplay

#### **Summaryビュー統合**
- **予約一覧表示**: Weather Forecastの下に配置
- **タイプ別グループ化**: 飛行機、ホテル、レンタカー等で分類
- **件数表示**: 各カテゴリの予約件数をバッジで表示

#### **Vertical Card風レイアウト**
- **固定幅**: 220px幅で統一されたカードデザイン
- **画像ヘッダー**: place_cacheの写真を背景に表示
- **ホバーエフェクト**: カードの浮き上がりアニメーション
- **レスポンシブ**: 1-4列のグリッドレイアウト

#### **時刻表示ルール**
- **同じ日**: `09:00 〜 14:30`
- **同じ月**: `09:00 〜 15日 14:30`
- **同じ年**: `09:00 〜 12/15 14:30`
- **異なる年**: `09:00 〜 2024/12/15 14:30`

## 🔧 技術改善

### 🎨 アイコンシステム刷新

#### **Iconify統合**
- **Tabler Icons**: 統一されたSVGアイコンセット
- **絵文字廃止**: カテゴリアイコンをSVGに移行
- **UnifiedIcon**: 軽量なアイコンコンポーネント

#### **アイコンマッピング**
```typescript
const iconifyByType = {
  flight: 'tabler:plane',
  rental_car: 'tabler:car', 
  hotel: 'tabler:bed',
  dining: 'tabler:tools-kitchen-2',
  other: 'tabler:bookmark'
}
```

### 🖼️ 画像表示改善

#### **place_cache連携**
- **実際の写真**: Google Places APIの写真をカードヘッダーに表示
- **フォールバック**: 写真がない場合はグラデーション+アイコン
- **最適化**: 400px幅での効率的な画像読み込み

### ⏰ 日時処理改善

#### **ローカル時刻対応**
- **UTC問題解決**: 予約編集画面でのUTC表示を修正
- **formatForDatetimeLocal**: ローカル時刻フォーマッター実装
- **一貫性**: 全UIでローカル時刻を統一

## 🎯 UX改善

### 📅 日付入力の改善

#### **Trip作成・編集**
- **自動設定**: 出発日入力時に帰宅日を自動設定
- **バリデーション**: 出発日以前の日付選択を無効化
- **min属性**: HTML5の日付入力制限を活用

#### **ReservationInfoModal**
- **時刻連動**: 開始時刻変更時に終了時刻を自動調整
- **飛行機**: 出発時刻+2時間で到着時刻を設定
- **その他**: 開始日+1日で終了日を設定

### 🎨 視覚的改善

#### **カードデザイン**
- **階層化**: ヘッダー・ボディ・フッターの3層構造
- **情報整理**: 重要度に応じた情報配置
- **アクセシビリティ**: 適切なコントラストとフォーカス表示

#### **インタラクション**
- **ホバーエフェクト**: カードの浮き上がりアニメーション
- **トランジション**: スムーズな状態変化
- **レスポンシブ**: デバイスサイズに応じた最適表示

## 🔒 セキュリティ・バリデーション

### 🌐 URL検証

#### **予約サイトURL**
- **HTTPS必須**: セキュアな接続のみ許可
- **ドメイン制限**: 許可された予約サイトのみ
- **許可ドメイン**: Expedia、Booking.com、ANA、JAL等

### ✅ データ検証

#### **予約情報バリデーション**
- **必須フィールド**: 予約タイプ、日時情報
- **論理チェック**: 開始日時 < 終了日時
- **空港コード**: 3文字の英大文字のみ
- **便名**: 航空会社コード+数字の形式
