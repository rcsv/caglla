## 📋 概要

現状のTripMapでは、検索窓（`MapSearchOverlay`）がマップ上部中央に大きく表示されており、フィルタ状態を示すオーバーレイダイアログはマップ左上に配置されている。検索を行っていないときでも横幅が広いため、地図上の情報が隠れてしまい、右ペイン（Itineraryリスト）との視認性にも影響が出ている。

ユーザーの操作性と視認性を高めるため、検索窓とフィルタ表示の配置・サイズ・表示状態を以下の仕様に沿って改善したい。

---

## 🐛 現状
1. `MapSearchOverlay` は `position="top-center"` で固定されており、横幅は `min(640px, 92vw)`。検索未使用時でも大きい。
2. フィルタ状態ダイアログ（`TripMap` 内部で直接描画）は左上に固定。ズームボタンと離れているため視線移動が発生。
3. 検索窓は常に不透明（`bg-white/90`）で、地図の視認性を阻害する。
4. フォーカス時・非フォーカス時でレイアウト変化がないため、マップ上の操作スペースが固定化されている。

---

## ✅ 期待する挙動
1. **検索窓の配置変更**
   - `MapSearchOverlay` をマップ左上（既存フィルタオーバーレイ位置）へ移動。
   - `TripMap` 内のフィルタオーバーレイは右上（ズームボタンの上／横）へ移動。

2. **検索窓のコラプス表示**
   - 非フォーカス（未入力）時は横幅 ≈ `80px`・半透明化（例: `bg-white/50` + `backdrop-blur`）で、アイコンとプレースホルダーのみ視認できる状態。
   - ホバーorフォーカス時に透明度を下げて不透明にし、横幅を右ペイン内に収まる最大値（例: `min(420px, 36vw)`）までアニメーション拡大。
   - 収縮時は検索結果ポップオーバーを閉じる。

3. **検索動作時のUX**
   - フォーカスが外れても検索結果リストが開いている場合は一定時間（例: 300ms）保持し、その後自動で閉じるかクリックで閉じる挙動を検討。
   - `Escape` キーで即時に閉じる操作もサポートできると望ましい。

4. **フィルタ状態ダイアログの配置**
   - ズームコントロール等との干渉を避けつつ、右上に固定配置。
   - スマホ画面ではオーバーレイスロットが重ならないようレスポンシブ対応を確認。

---

## 🔍 技術的考慮事項
- `MapSearchOverlay` は `position`・`width` をpropsで制御している。今回の仕様では「通常時」「展開時」の2状態を内部で持たせる必要がある。
- Tailwindユーティリティクラスでのアニメーション制御（`transition-all`, `duration-200`, `ease-out` 等）を用いるか、CSSモジュールで詳細制御を行うか判断が必要。
- 半透明時に背景地図が読めるよう、`pointer-events` の扱い（検索アイコンやインプットへのフォーカス nav）に注意。薄い状態でもクリック可能にするには `bg-white/50` + `backdrop-blur` 程度が妥当。
- 右ペイン幅はレイアウトによって変動するため、`max-width` を `%` と `px` の組み合わせで制約する。`calc(100% - 32px)` など、左右パディングを考慮した値が必要。
- フォーカスの有無を判定するために `onFocus` / `onBlur` に加えて検索結果クリック時の挙動を管理する必要がある（`setTimeout` + `document.activeElement` チェック等）。
- モバイル表示では、80pxスモール状態のタップヒットが確保できるよう、最低高さやタップターゲットを確認。
- フィルタオーバーレイを右上に移動する際、Google Mapのズーム＋レイヤーコントロールと重ならないよう `ControlPosition` をカスタマイズする可能性がある。必要に応じてズームコントロールの位置調整も検討。

---

## 🧪 テスト観点
- PC表示で検索窓が縮小状態→クリック/フォーカスで拡大→入力→Enter/候補選択→フォーカスアウトで再縮小すること。
- スクロールや他UI操作後でも検索窓が正しい位置・サイズに戻ること。
- モバイル幅で右ペインが非表示の場合、検索窓・フィルタダイアログがマップ上に収まり、Google提供コントロールと競合しないこと。
- フィルタ有効時（特定の日を選択）に右上のステータスが正しく表示され続けること。
- ダークモード（存在する場合）やテーマ変更による視認性が確保されていること。
