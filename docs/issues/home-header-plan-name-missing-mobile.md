# Home Header Plan Name Hidden on Mobile

- **Priority**: P1（課金情報の確認不能、CVR 低下）
- **URL**: `/home`
- **Viewport**: width < 640px
- **Component**: `app/home/page.tsx` のユーザー情報ブロック（ヘッダー右側）
- **Epic**: Header responsive content visibility

## ステータス

- ✅ Fixed (2025-11-11) — `HomeHeader` のプラン名をモバイルでもバッジ表示するよう更新

## 現象

ヘッダー右側のユーザー情報ブロックに含まれるプラン名（例: "Globetrotter"）がモバイル幅で非表示になる。プロフィール画像と名前は残るが、プラン情報が確認できない。

## 再現手順

1. ログインし `/home` を開く。
2. ビューポートを 640px 未満に縮める。
3. ヘッダー右側のユーザーブロックを確認する。

## 期待結果

モバイルでもプラン名が省略形またはバッジなどで表示され、課金状況がわかる。

## 実際の結果

プラン名テキストが消え、ドロップダウンを開いても確認できない。

## 原因仮説

- プラン名表示が `hidden md:block` で制御されている。
- モバイル用のバッジ表示（例: "Free", "Pro", "Premium" アイコン）が実装されていない。

## 受け入れ基準

- [ ] 640px 未満でもプラン名の短縮形（例: "Free", "Pro", "Globetrotter"）またはバッジが表示される
- [ ] プラン名の色分けでプラン種別を視覚的に区別できる（例: Free=灰色、Pro=青、Premium=金色）
- [ ] プラン名をタップするとプラン変更ページへ遷移できる
- [ ] タップ領域は 44x44px 以上

## アクセシビリティ

- プラン名はスクリーンリーダーで読み上げられる（`aria-label="Current plan: Globetrotter"`）。
- プラン変更リンクはキーボードで到達可能。

## メモ

- プラン変更導線（Change Plan）がモバイルでより重要になるため、現状の非表示は UX を損ねる。
- バッジ化することで視認性と操作性を両立できる。
- 対応PR: `components/common/HomeHeader.tsx` にプランバッジスタイルを追加。
