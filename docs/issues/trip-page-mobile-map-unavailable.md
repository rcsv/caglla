# Trip Page Mobile Map Unavailable

- **Priority**: P0（核心機能の利用不能）
- **URL**: `/[userSlug]/[tripSlug]`
- **Viewport**: width < 640px
- **Component**: `components/trip/TripRightPane.tsx`, `components/trip/TripMap.tsx`
- **Epic**: Trip mobile IA/ナビゲーション再設計

## ステータス

- ✅ Fixed (2025-11-11) — フローティングマップボタン＋フルスクリーンモーダルでモバイル地図を実装

## 現象

モバイル幅では右ペイン（地図表示）が丸ごと非表示になる。地図モードに切り替える導線もなく、旅行データの地理情報を確認できない。

## 再現手順

1. トリップページをモバイル幅で開く。
2. 右側のマップ領域がレンダーされないことを確認。
3. ビューを切り替えても地図を開く手段が見つからない。

## 期待結果

モバイルでもマップを閲覧できる導線（タブやダイアログなど）が提供される。

## 実際の結果

`md:block` 制御によりマップ関連 UI が非表示のまま。

## 原因仮説

- `TripRightPane` が `hidden md:block` で制御され、640px 未満では DOM から削除される。
- モバイル用のマップ表示 UI（フローティングボタン、モーダル、タブなど）が実装されていない。
- Google Maps API がモバイルでは初期化されない可能性。

## 受け入れ基準

- [ ] 640px 未満で地図表示ボタンが画面下部または右下にフローティング表示される
- [ ] ボタンタップでフルスクリーンまたはモーダルで地図が開く
- [ ] 地図上のマーカーはデスクトップと同じ機能（クリックで詳細表示、ルート表示など）
- [ ] 地図を閉じるボタン（×）が右上に表示される
- [ ] フローティングボタンのタップ領域は 56x56px 以上（FAB 基準）

## 解決方針（案）

### 案1: フローティングボタン + フルスクリーンモーダル
1. `FloatingTitleBar` または画面右下にマップアイコンボタンを配置（`md:hidden`）
2. ボタンタップで地図をフルスクリーンモーダルで表示
3. モーダル内で `TripMap` コンポーネントを再利用

### 案2: タブ切り替え（Map / List）
1. モバイル専用のタブを追加（`Summary`, `Itinerary`, `Checklist`, `Map`）
2. `Map` タブを選択すると地図がメインコンテンツ領域に表示される
3. 右ペインを完全に削除し、タブで統一

### 案3: ボトムシート
1. 画面下部から地図をスワイプアップで表示
2. ハーフサイズとフルサイズを切り替え可能
3. iOS / Android のネイティブ UI に近い体験

## アクセシビリティ

- マップボタンは `<button>` 要素で実装し、`aria-label="Open map"` を付与。
- モーダルが開いた時、フォーカスはモーダル内に移動。
- Escape キーでモーダルを閉じる。

## メモ

- 別タブやモーダルでマップを表示する案を検討する。
- Google Maps の性能を考慮し、モーダル表示時のみ地図を初期化する（遅延ロード）。
- ルート最適化機能もモバイルで利用できるよう設計する。
- 対応PR: `app/[userSlug]/[tripSlug]/page.tsx` にフローティングボタンとモーダルマップを追加。
