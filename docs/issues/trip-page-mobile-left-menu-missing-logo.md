# Trip Page Mobile Left Menu Missing Logo

- **Priority**: P2（ブランド認識・一貫性）
- **URL**: `/[userSlug]/[tripSlug]`
- **Viewport**: width < 640px
- **Component**: `components/planner/NavigationMenu.tsx`
- **Epic**: Trip mobile IA/ナビゲーション再設計

## ステータス

- ✅ Fixed (2025-11-11) — モバイルメニューでもロゴを表示し、ロゴタップでメニューを閉じるよう改善

## 現象

モバイル用スライドメニュー内に Caglla ロゴが表示されず、ブランド認識が弱い。デスクトップではロゴ＋テキストが見えているが、モバイルでは白紙になっている。

## 再現手順

1. トリップページをモバイル幅で開く。
2. ハンバーガーで左メニューを表示。
3. メニュー上部のロゴ領域が空欄になっていることを確認。

## 期待結果

モバイルのメニューでもロゴまたはサービス名が表示される。

## 実際の結果

ロゴコンポーネントがレンダーされず、空のスペースだけが残る。

## 原因仮説

- `NavigationMenu` のロゴ部分が `md:block` などで制御され、モバイルで非表示になっている。
- モバイル用スライドメニューのマークアップでロゴコンポーネントが省略されている。
- CSS の z-index やオーバーレイ問題でロゴが背景に隠れている可能性。

## 受け入れ基準

- [ ] 640px 未満のスライドメニュー上部にロゴ＋「Caglla」テキストが表示される
- [ ] ロゴはホームページ (`/home`) へのリンクとして機能する
- [ ] ロゴのタップ領域は 44x44px 以上
- [ ] デスクトップと同じロゴデザインが使用される

## 解決方針

1. `NavigationMenu` のロゴ部分にモバイル専用の表示条件を追加
2. スライドメニュー用の `CagllaLogo` コンポーネントを常時レンダー
3. ロゴクリック時にメニューを自動クローズして `/home` へ遷移

## アクセシビリティ

- ロゴリンクは `<Link>` 要素で実装し、`aria-label="Go to home"` を付与。
- キーボードで到達可能。

## メモ

- `NavigationMenu` の `md:hidden` 条件やロゴ用クラスがモバイルで非表示になっている可能性。
- デスクトップの左ナビと同じコンポーネントを使い回しているため、モバイル専用の条件分岐が必要。
- 対応PR: `components/planner/NavigationMenu.tsx` でロゴに `flex-shrink-0` を追加し、モバイル幅ではタップ時にメニューが閉じるように処理。
