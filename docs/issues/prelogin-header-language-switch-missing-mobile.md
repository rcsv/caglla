# Pre-login Header Language Switch Hidden on Mobile Width

- **Priority**: P0（多言語対応の核心機能が利用不能）
- **URL**: `/`, `/blog`, その他ログイン前ページ
- **Viewport**: width < 640px (mobile)
- **Component**: `app/page.tsx`, `app/blog/page.tsx` のヘッダー言語切り替えコンポーネント
- **Epic**: Header responsive content visibility

## ステータス

- ✅ Fixed (2025-11-11) — `LandingHeader` で `LanguageSwitcher` を常時表示（モバイル幅向けの幅・フォントを調整）

## 現象

モバイル幅にするとヘッダー右側にある言語切り替えスイッチが完全に非表示になる。言語を変更する術がなく、初回訪問者が希望言語に切り替えられない。

## 再現手順

1. ログアウトした状態で `http://localhost:3000/` にアクセス。
2. ビューポートを 640px 未満に縮小。
3. ヘッダー右端を確認する。

## 期待結果

モバイルでも言語切り替えトグルが表示され、操作できる。

## 実際の結果

コンポーネントごと非表示になり切り替えができない。

## 原因仮説

- 言語切り替えボタンが `md:flex` や `hidden md:block` で制御され、640px 未満で非表示になっている。
- モバイル用の代替 UI（ドロップダウン・ハンバーガーメニュー内配置）が実装されていない。

## 受け入れ基準

- [ ] 640px 未満でも言語切り替え UI（ドロップダウンまたはアイコンボタン）が表示される
- [ ] タップ領域は 44x44px 以上を確保
- [ ] 言語選択後、即座にページが再レンダリングされ選択言語で表示される
- [ ] 現在選択中の言語が視覚的に明示される（フラグアイコンやラベル）

## アクセシビリティ

- 言語切り替えボタンは `role="button"` または `<button>` 要素で実装。
- 選択中の言語を `aria-current="true"` で示す。
- キーボードで操作可能（Tab で到達、Enter/Space で選択）。

## メモ

- 多言語対応が売りのアプリなので、モバイルでも最低限ドロップダウン等で提示したい。
- グローバル i18n 設定に影響するため、初回訪問時の言語検出が重要。
- 対応PR: `components/common/LandingHeader.tsx` にて `hidden md:inline-block` を撤廃し、モバイルでも操作可能なスタイルへ変更。
