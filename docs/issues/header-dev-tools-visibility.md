## 🐛 問題の詳細

### 現状
- HeaderにDev Toolsが常に表示されている

### 期待される動作
1. **デバッグスイッチ連動**: デバッグモードが有効な時のみ表示
2. **バッジ表示**: デバッグメニューであることを視覚的に示す（例：`[DEBUG]`バッジ）
