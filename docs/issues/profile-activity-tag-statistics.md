# Feature: プロフィールページにアクティビティタグ統計を表示

**作成日**: 2025-10-31  
**状態**: 🔴 未実装  
**優先度**: 中  
**関連ファイル**:
- `app/[userSlug]/page.tsx`（プロフィールページ）
- `lib/core/types/activity.ts`（ActivityTag型定義）
- `app/api/users/[userId]/activity-stats/route.ts`（新規APIエンドポイント）
- `components/stats/ActivityStatsDisplay.tsx`（既存の統計表示コンポーネント - 参考）

---

## 📋 概要

プロフィールページに、ユーザーの旅行傾向を示すアクティビティタグの統計情報を表示する。例えば「この人は買い物が好き」「飛行機での移動が多い」「ビーチが大好き」などの傾向を視覚的に分かりやすく表示する。

---

## 🎯 機能要件

### 基本機能
1. **アクティビティタグの集計**
   - ユーザーが作成したすべてのItineraryの`activity_tag`を集計
   - タグごとの出現回数と割合を計算

2. **統計情報の表示**
   - 上位のアクティビティタグ（TOP 5など）を視覚的に表示
   - バーグラフ、ドーナツチャート、またはリスト形式
   - タグ名、出現回数、割合を表示

3. **傾向の可視化**
   - 「ショッピングが多い」「ビーチが好き」などの傾向を一目で分かるように
   - カテゴリ別の色分け（オプション）

### 高度な機能（将来）
- 期間別の統計（直近1年、直近6ヶ月など）
- カテゴリ別の詳細表示
- 旅行先の国・地域との関連付け
- 他のユーザーとの比較（オプション）

## 📝 技術的検討事項

### 集計のタイミング
- **リアルタイム集計**: プロフィールページ表示時に毎回計算（シンプルだが遅い可能性）
- **事前集計**: バックグラウンドジョブで定期的に集計し、結果を保存（高速だが複雑）

### キャッシュ戦略
- Firestoreのドキュメントに統計結果をキャッシュ
- Itineraryが更新されたときに統計も更新
- 1日1回の再計算など

### アクティビティタグの構造
- 2段階分類の場合（例: `{ category: 'shopping', subcategory: 'market' }`）
- カテゴリ単位で集計するか、サブカテゴリ単位で集計するか
- 両方の表示をサポートするか
