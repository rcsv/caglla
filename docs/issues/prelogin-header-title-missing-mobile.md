# Pre-login Header Title Missing on Narrow Viewports

- **Priority**: P0（初回訪問の認知・離脱に直結）
- **URL**: `/`, `/blog`, その他ログイン前ページ
- **Viewport**: width < 640px (mobile)
- **Component**: `app/page.tsx`, `app/blog/page.tsx` のヘッダー実装箇所
- **Epic**: Header responsive content visibility

## 現象

モバイル幅にブラウザを縮めるとヘッダー内のサービス名タイトルが完全に非表示になる。ロゴは残るがテキストが消えるため、ブランド名の認識がしづらい。

## 再現手順

1. ブラウザで `http://localhost:3000/` を開く。
2. デベロッパーツールなどで viewport を 640px 未満に縮める。
3. ページ最上部のヘッダーを確認する。

## 期待結果

モバイルでもサービス名（例: "Caglla"）が視認できる形で表示される。

## 実際の結果

タイトル文字が DOM から削られるか、スタイルで `display: none` になっており表示されない。

## 原因仮説

- ヘッダーコンポーネント内の要素が `md:` ブレークポイントに依存しており、640px 未満で強制的に非表示になる。
- デスクトップレイアウトを前提にした `hidden sm:block` などのクラスが原因の可能性。

## 受け入れ基準

- [ ] 640px 未満でも「Caglla」テキストまたは短縮形が常時表示される
- [ ] ロゴとテキストが適切な間隔で配置され、視認性が確保される
- [ ] タイトルの最小タップ領域は 44x44px 以上（WCAG AAA 基準）
- [ ] コントラスト比は背景に対して 4.5:1 以上

## アクセシビリティ

- テキストが非表示の場合、スクリーンリーダーでサービス名を伝えるための `aria-label` が必要。
- フォーカス可能な要素がロゴのみの場合、キーボードナビゲーションで不利。

## メモ

- ロゴアイコンだけでは初回訪問の認知が弱い。
- レスポンシブ対応を入れる場合、横幅が足りなくても縮小表示や折返しなどでブランド名を保持したい。
