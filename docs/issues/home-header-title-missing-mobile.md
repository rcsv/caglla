# Home Header Title Missing on Mobile Width

- **Priority**: P0（現在地の把握不能）
- **URL**: `/home`
- **Viewport**: width < 640px
- **Component**: `app/home/page.tsx` のヘッダー実装箇所
- **Epic**: Header responsive content visibility

## ステータス

- ✅ Fixed (2025-11-11) — `HomeHeader` のアプリ名ラベルをモバイルでも表示するよう更新

## 現象

ログイン後のホーム画面でビューポートをモバイル幅にすると、ヘッダー左側に表示されるはずのページタイトルが消える。ロゴの隣が空白になり、利用者が現在のページを視覚的に把握しづらい。

## 再現手順

1. ログインして `/home` にアクセス。
2. ビューポート幅を 640px 未満に調整。
3. ヘッダー上部を確認する。

## 期待結果

モバイルでもページタイトルやセクション名が簡潔に表示される。

## 実際の結果

タイトルが DOM から削除されるか `display: none` となっており視認できない。

## 原因仮説

- ヘッダータイトルが `hidden md:block` で制御されている。
- モバイル用の短縮タイトルや代替 UI（パンくず・アイコンバッジなど）が用意されていない。

## 受け入れ基準

- [ ] 640px 未満でもページタイトル（例: "Home", "旅行一覧"）が表示される
- [ ] タイトルが長い場合は省略形（例: "Home" のみ）で表示される
- [ ] タイトルとロゴが適切な間隔で配置される
- [ ] ヘッダー高さは最大 60px 以内に収まる

## アクセシビリティ

- ページタイトルは `<h1>` または `aria-label` でスクリーンリーダーに伝える。
- 視覚的に非表示でも、セマンティック HTML でページ構造を明示。

## メモ

- 代わりにパンくずやタブを表示する案も検討可能。
- デスクトップと同じタイトルをそのまま使うと幅が足りないため、短縮または省略が必要。
- 対応PR: `components/common/HomeHeader.tsx` のクラス見直し（`hidden sm:inline` を撤廃し、モバイル向けフォントサイズを追加）。
