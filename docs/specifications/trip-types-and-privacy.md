# 旅行データの種類と属性仕様

このドキュメントは、Caglla Travel Managerにおける旅行データの種類と属性、プライバシー設定を整理したものです。

---

## 📋 旅行データの3つのタイプ

### 1. プライベート旅行（Private Trip）

**概要**: 通常の旅行管理用途。招待されたメンバーでのみ共有される旅行データ。

**属性**:
- `access_level`: `'private'`
- `is_template`: `false`
- `is_shared`: `false` または未設定（新規フィールド）

**特徴**:
- **閲覧権限**: オーナー + 招待されたユーザーのみ（`trip_users`コレクションで管理）
- **日付情報**: 出発日・帰宅日を明確に設定（`start_date`, `end_date`が必須）
- **詳細情報**: すべての情報（宿泊先、予約情報、チェックリストなど）を完全に表示
- **公開範囲**: Feed / Profile には表示されない（招待されたメンバーのみ）
- **招待メンバー表示**: 会議の参加者リストのように、誰がこの旅行にアクセスできるかが明確に表示される
  - オーナーは「オーナー」バッジとクラウンアイコンで表示
  - 招待メンバーは「招待済み」バッジとチェックマークで表示
  - メンバーの追加・削除が可能

**ユースケース**:
- 家族旅行の計画・管理
- 友人同士の旅行の調整
- 会社の出張スケジュール管理

**データモデル例**:
```typescript
{
  id: "trip-123",
  user_id: "user-abc",
  title: "家族で沖縄旅行",
  access_level: "private",
  is_template: false,
  start_date: Timestamp(2024-12-15T00:00:00Z),
  end_date: Timestamp(2024-12-18T00:00:00Z),
  // ... その他のフィールド
}
```

---

### 2. プライベート旅行のシェア（Shared Private Trip）

**概要**: プライベート旅行を「参考情報」として公開するモード。プライバシーに配慮して一部情報をぼやかす。

**属性**:
- `access_level`: `'public'`
- `is_template`: `false`
- `is_shared`: `true`（新規フィールド）
- `shared_from_trip_id`: 元のプライベート旅行のID（新規フィールド）

**特徴**:
- **閲覧権限**: 誰でも閲覧可能（パブリック）
- **日付情報**: プライバシー保護のため、具体的な日付は非表示。**月のみ**表示（例: "2024年12月"）
  - `shared_start_month`: 月のみ（1-12）
  - `shared_start_year`: 年のみ
  - `shared_end_month`: 月のみ（1-12）
  - `shared_end_year`: 年のみ
  - **重要**: 具体的な日（例: 12月15日）は表示しない
  - **理由**: ストーカーなどの悪意のあるユーザーが現地での行動を把握できないよう、プライバシーを保護するため
- **日程表示**: プライバシー保護のため、日程は「1日目」「2日目」として表示
  - 具体的な日付（例: 12月15日）は表示しない
  - 日付ベースの表示を避け、相対的な日数表示のみ
  - **理由**: 現地での具体的な行動パターンを推測できないようにするため
- **詳細情報の制限**:
  - 宿泊先情報を非表示または匿名化（例: "那覇市内のホテル"）
  - 予約情報（reservation）を非表示
  - チェックリストは非表示
  - 旅程（itinerary）のタイムスタンプをぼやかす
  - 現地での具体的な行動パターンを推測できないようにする
- **公開範囲**: Feed / Profile に表示される
- **プライバシー保護**: ストーカーなどの悪意のあるユーザーが現地での行動を把握できないよう、日付と日程情報を最小限に。具体的な日付を非表示にすることで、プライバシーを保護します。

**ユースケース**:
- 旅行プランの参考情報として共有
- 「こんな旅行をしました」という記録として公開
- 他人の旅行計画の参考にしたい

**データモデル例**:
```typescript
{
  id: "trip-shared-123",
  user_id: "user-abc",
  title: "沖縄旅行のプラン（参考）",
  access_level: "public",
  is_template: false,
  is_shared: true,
  shared_from_trip_id: "trip-123",
  // 具体的な日付は非表示
  start_date: undefined, // または削除
  end_date: undefined,   // または削除
  // 月のみの情報
  shared_start_month: 12,
  shared_start_year: 2024,
  shared_end_month: 12,
  shared_end_year: 2024,
  // ... その他のフィールド（宿泊先情報は削除または匿名化）
}
```

**表示ロジック**:
- `start_date` / `end_date` が存在する場合は通常通り表示
- `is_shared === true` かつ `start_date` / `end_date` が存在しない場合は `shared_start_month/year` を使用して「2024年12月」と表示（「頃」は付けない、具体的な日は非表示）
- 日程は「1日目」「2日目」として表示（具体的な日付は非表示）
- 宿泊先の `reservation` フィールドは表示しない（フィルタリング）
- プライバシー保護のため、現地での行動パターンを推測できないよう、日付情報を最小限に

### 3. 旅行プランのシェア（Travel Plan / Template）

**概要**: 日付を設定しない旅行プラン。ツアー呼び込みや地域の楽しみ方を紹介するためのテンプレート。

**属性**:
- `access_level`: `'public'`（作成中は一時的に `'private'` も可）
- `is_template`: `true`
- `shared_plan_type`: `'user' | 'business'`（新規フィールド、オプショナル）

**特徴**:
- **閲覧権限**: 誰でも閲覧可能（パブリック）
- **日付情報**: 出発日・帰宅日は設定しない。旅行期間のみ提示（例: "3泊4日"）
  - `day_count`: 日数（必須）
  - `start_date`: 未設定
  - `end_date`: 未設定
- **詳細情報**: 
  - 旅程は「一日目」「二日目」として表示
  - 地域の楽しみ方、効率的な移動方法を紹介
  - 宿泊先はエリア情報のみ（具体的なホテル名は非表示または一般化）
- **公開範囲**: Feed / Profile / Templates ページに表示される
- **業者レコメンド**: `shared_plan_type === 'business'` の場合は業者のプランとして表示

**ユースケース**:
- 「沖縄3泊4日の楽しみ方」のようなプラン共有
- ツアー会社のプラン提案
- 友人からのおすすめルートの紹介
- 地域の効率的な移動方法の共有

**データモデル例**:
```typescript
{
  id: "template-456",
  user_id: "user-abc",
  title: "沖縄3泊4日の楽しみ方",
  access_level: "public",
  is_template: true,
  day_count: 4,
  // 日付は設定しない
  start_date: undefined,
  end_date: undefined,
  shared_plan_type: "user", // または "business"
  // ... その他のフィールド
}
```

**表示ロジック**:
- `is_template === true` の場合、「一日目」「二日目」として表示
- `day.date` が存在しない場合は、`day.day_number` を使用して「1日目」「2日目」と表示
- カレンダー表示は非表示またはグレーアウト

## 🔄 旅行タイプの切り替え

### プライベート旅行 → プライベート旅行のシェア

1. ユーザーが「シェアする」ボタンをクリック
2. システムが自動的に以下の処理を実行:
   - 新しいTripを作成（`is_shared: true`, `shared_from_trip_id` を設定）
   - 日付情報を月のみに変換（`shared_start_month/year`, `shared_end_month/year`）
   - 宿泊先情報を削除または匿名化
   - 予約情報を削除
   - `access_level` を `'public'` に変更
3. 元のプライベート旅行は変更されない（`access_level: 'private'` のまま）

### プライベート旅行 → 旅行プランのシェア

1. ユーザーが「プランとして公開」ボタンをクリック
2. システムが自動的に以下の処理を実行:
   - `is_template: true` に設定
   - `start_date` / `end_date` を削除（`day_count` は維持）
   - `access_level` を `'public'` に変更（作成中は `'private'` も可）
3. 元のプライベート旅行は変更されない（別エンティティとして管理することも可能）

## 📊 データモデルの拡張

### 新規フィールド

```typescript
export interface Trip {
  // ... 既存フィールド
  
  // プライベート旅行のシェア用
  is_shared?: boolean                    // プライベート旅行のシェア版かどうか
  shared_from_trip_id?: string          // 元のプライベート旅行のID
  shared_start_month?: number           // シェア時の開始月（1-12）
  shared_start_year?: number            // シェア時の開始年
  shared_end_month?: number             // シェア時の終了月（1-12）
  shared_end_year?: number              // シェア時の終了年
  
  // 旅行プランのシェア用
  shared_plan_type?: 'user' | 'business' // プランの種類（ユーザー/業者）
}
```

## 🎨 UI/UX の実装指針

### プライベート旅行の表示

- すべての情報を完全に表示
- カレンダーに正確な日付で表示
- 編集・削除機能を提供
- **招待メンバーセクション**: 会議の参加者リストのように表示
  - オーナー: クラウンアイコン + 「オーナー」バッジ + インディゴ背景
  - 招待メンバー: アバター + 名前 + メールアドレス + 「招待済み」バッジ + チェックマーク
  - メンバー削除ボタン（オーナーのみ）
  - 「メンバーを招待」ボタン（オーナーのみ）

### プライベート旅行のシェアの表示

- 日付は「2024年12月」と表示（具体的な日は非表示、プライバシー保護のため）
- 日程は「1日目」「2日目」として表示（具体的な日付は非表示）
- 宿泊先は「那覇市内のホテル」など、エリア情報のみ
- 予約情報（reservation）は表示しない
- 「参考情報として共有」バッジを表示
- 「プライバシー保護」バッジを表示（日付情報がぼかされていることを明示）
- **写真ギャラリー表示**: InstagramやFacebookの写真投稿のように、ビジュアル重視のタイムライン形式
  - 各itinerary（予定）にアップロードした写真が紐づいて表示される
  - 写真はホバーで拡大表示、場所情報がオーバーレイで表示される
  - 各写真にいいね・コメント・シェアボタンが表示される
  - 複数写真がある場合は写真数バッジを表示
  - 日付ヘッダーはグラデーション背景で視覚的に区別

### 旅行プランのシェアの表示

- 日付は「3泊4日」など、期間のみ表示
- 日程は「一日目」「二日目」として表示
- カレンダー表示は非表示またはグレーアウト
- `shared_plan_type === 'business'` の場合は「業者プラン」バッジを表示
- 「Use this template」ボタンを表示
- **クリエイタープロフィール表示**: プランを作成したクリエイターのプロフィールを表示
  - アバター画像（業者の場合は店舗アイコン付き）
  - クリエイター名とメールアドレス
  - 自己紹介文（bio）
  - 統計情報（公開プラン数、総いいね数、フォロワー数）
  - アクションボタン（フォロー、メッセージ、プロフィールを見る）
  - 業者プランの場合は「業者プラン」バッジ、ユーザープランの場合は「ユーザープラン」バッジを表示

## 🔍 Feed での表示

### Feed の並び順

1. **プライベート旅行のシェア**: 通常のフィードとして表示（`is_shared === true` かつ `access_level === 'public'`）
2. **旅行プランのシェア**: テンプレートタブまたは通常フィードに表示（`is_template === true` かつ `access_level === 'public'`）
3. **業者プラン**: `shared_plan_type === 'business'` の場合は特別なセクションまたはタグで区別

### フィルタリング

- Feed では `access_level === 'public'` のもののみ表示
- `is_shared === true` のものも Feed に含める
- `is_template === true` のものは Templates タブまたは通常の Feed に表示

## 🔐 プライバシーとセキュリティ

### プライベート旅行

- `trip_users` コレクションで招待メンバーを管理
- 招待されていないユーザーは閲覧不可（403エラー）
- API レベルでアクセス制御を実装

### プライベート旅行のシェア

- 公開前にユーザーに確認ダイアログを表示
  - 「宿泊先情報を削除しますか？」
  - 「日付を月のみに変更しますか？」
- シェア後の編集は制限（元のプライベート旅行と同期しない）

### 旅行プランのシェア

- 作成中は `access_level: 'private'` でも可
- 公開時に確認ダイアログを表示
- 業者プランの場合は認証・承認フローを検討
