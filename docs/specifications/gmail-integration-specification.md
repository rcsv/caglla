# Gmail連携自動予約抽出機能 仕様書

**対象バージョン**: v1.12.0  
**作成日**: 2025-10-20  
**ステータス**: 設計中（概要のみ）

---

## 📌 エグゼクティブサマリー

### 概要
Gmail APIを利用して予約確認メールを自動検出し、AI（OpenAI GPT-4）で予約情報を抽出してCagllaに自動登録する機能。

### 主要機能
- **自動メール検出**: 航空券・ホテル・レンタカー等の予約確認メールを自動識別
- **AI情報抽出**: OpenAI GPT-4 + 正規表現パターンマッチング
- **自動同期**: 手動・定期（1時間/1日/1週間）の同期オプション
- **確認・編集**: ユーザーによる内容確認と手動編集

### 技術スタック
- Gmail API（OAuth 2.0）
- OpenAI GPT-4 API
- Firestore

### プラン別制限
- **Season Traveler**: ❌ 利用不可
- **Backpacker**: 月間10メール抽出まで
- **Globetrotter**: 無制限

### コスト
- 1メールあたり約4円（OpenAI API）
- 月額約4,000円（ユーザー100人想定）

### 実装期間
約8週間（2ヶ月）
