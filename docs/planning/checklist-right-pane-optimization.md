# チェックリスト右ペイン情報配置最適化案

## 現状の問題点

`longDescription`が400-800文字と長くなり、以下の問題が発生：

1. **情報の優先順位が不明確**: 重要な情報（優先度、カテゴリ）が`longDescription`に埋もれる
2. **スクロールが多すぎる**: ユーザーメモ、`longDescription`、進捗状況、関連アイテムが縦に並び、スクロールが必要
3. **情報の階層が不明確**: どの情報が重要か、どこを見ればいいか分かりにくい

## 最適化案

### 案1: 固定ヘッダー + スクロール可能コンテンツ（推奨）

**構成：**
```
┌─────────────────────────────────┐
│ [固定] カテゴリ / 生成根拠      │ ← 常に表示
│ [固定] タイトル + 優先度 + 閉じる│ ← 常に表示
│ [固定] ユーザーメモ（コンパクト）│ ← 常に表示（折りたたみ可能）
├─────────────────────────────────┤
│ [スクロール] 詳細説明            │ ← メインコンテンツ
│ [スクロール] 進捗状況            │
│ [スクロール] 関連アイテム        │
└─────────────────────────────────┘
```

**メリット：**
- 重要な情報（タイトル、優先度）が常に見える
- `longDescription`に集中できる
- ユーザーメモは必要に応じて展開

### 案2: タブ分割

**構成：**
```
┌─────────────────────────────────┐
│ [固定] タイトル + 優先度         │
│ [タブ] 詳細 | メモ | 関連        │
│ ┌─────────────────────────────┐ │
│ │ 選択したタブのコンテンツ     │ │
│ │ （longDescription など）    │ │
│ └─────────────────────────────┘ │
└─────────────────────────────────┘
```

**メリット：**
- 情報を明確に分離
- 各タブに集中できる

**デメリット：**
- タブ切り替えが必要
- 情報の全体像が見えにくい

### 案3: アコーディオン + 優先順位付け（推奨）

**構成：**
```
┌─────────────────────────────────┐
│ [固定] カテゴリ / 生成根拠      │
│ [固定] タイトル + 優先度 + 閉じる│
├─────────────────────────────────┤
│ ▼ 詳細説明（常に展開）          │ ← 最重要
│   [longDescription]             │
├─────────────────────────────────┤
│ ▶ ユーザーメモ（折りたたみ可能）│
│ ▶ 進捗状況（折りたたみ可能）    │
│ ▶ 関連アイテム（折りたたみ可能）│
└─────────────────────────────────┘
```

**メリット：**
- `longDescription`を最優先で表示
- 他の情報は必要に応じて展開
- 情報の階層が明確

## 推奨実装：案3（アコーディオン + 優先順位付け）

### 実装方針

1. **固定セクション（常に表示）**
   - カテゴリ情報（パンくずリスト）
   - タイトル + 優先度バッジ + 閉じるボタン

2. **メインコンテンツ（常に展開）**
   - `longDescription`（最重要）

3. **補助情報（折りたたみ可能）**
   - ユーザーメモ（デフォルト：折りたたみ）
   - カテゴリ内の進捗状況（デフォルト：折りたたみ）
   - 関連アイテム（デフォルト：折りたたみ）

4. **生成根拠**
   - カテゴリ情報のパンくずリストに統合（別セクション不要）

### 視覚的な改善

- `longDescription`の見出しを大きく、目立たせる
- 折りたたみ可能なセクションにはアイコン（▼/▶）を表示
- 各セクション間に適切な余白を設ける
